05 Complete System Architecture

OmniSocial AI implements a resilient, multi-tiered enterprise architecture ensuring strict isolation between user-facing clients, background workers, and persistent data stores.

Architectural Responsibilities by System Layer

Frontend Responsibilities (Next.js 14)

• Render responsive account cards, composer, and calendar.

• Validate media file size and aspect ratios client-side.

• Initiate OAuth redirection via backend API endpoints.

• Poll or subscribe to post publishing status events.

STRICT RESTRICTION: Zero direct database access, zero Meta API calls, zero access tokens stored in localStorage.

Backend Responsibilities (NestJS API & Workers)

• Orchestrate OAuth 2.0 PKCE state verification.

• Encrypt/decrypt tokens using TokenVaultService (AES-256-GCM).

• Enforce multi-tenant workspace access guards on all routes.

• Manage BullMQ queues, delayed jobs, and retries in Redis.

• Dispatch 2-step media container requests to Meta Graph API.
