02 Meta Developer Account & App Creation

To interact with Instagram's Graph API, OmniSocial AI must establish an official application identity within the Meta Developer ecosystem. Follow this exact sequence on https://developers.facebook.com/:

Step-by-Step Meta Developer Portal Walkthrough

Step Action & Dashboard Location Configuration Requirements Security Guardrail
01 Sign In & Registration Sign in with Meta account; complete developer registration; verify SMS. Enable 2FA on developer account
02 Create App > Use Case Select "Other" > "Business" app type. Name: OmniSocial AI. Assign to verified Business Portfolio
03 Add Products Add Instagram Graph API and Instagram Login. Do not add deprecated Basic Display
04 App Settings > Basic App Domains: omnisocial.ai. Add HTTPS Privacy Policy & Terms URLs. HTTPS strictly enforced in production
05 Valid OAuth Redirect URIs Add exact callback: https://api.omnisocial.ai/v1/oauth/meta/callback. No wildcards or localhost in prod
06 App Roles > Test Users Add development Instagram accounts as App Testers for sandbox testing. Testers must accept invite in IG settings
07 App ID & Secret Vault Copy App ID and App Secret into backend environment variables. Never commit App Secret to Git
